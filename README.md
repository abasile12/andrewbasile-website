# andrewbasile.com

Static portfolio site. No build step. Pages use clean URLs: `index.html` is the home page (/), `skills/index.html` is Skills & Automations (/skills/), `worktogether/index.html` is Work Together (/worktogether/) and `sidequests/index.html` is Side Quests (/sidequests/). The old `skills.html`, `worktogether.html` and `sidequests.html` files are redirect stubs; keep them so old links still work. Images and clips live in `assets/` (referenced as `/assets/...` from the sub-pages) and the downloadable skill zips live in `skills/`.

Published with GitHub Pages from the `main` branch at https://andrewbasile.work (the `CNAME` file sets the domain; keep it).
